FUNCTION BEFORE APPEARANCE

Non-Standard Mobility Aids

An unfamiliar form does not answer whether an aid serves a disability-related mobility function in a particular setting.

Review the questionsIndividual Case Study & Evidence

Start with the claimed function

Ask what mobility limitation is addressed, what task is enabled, what comparison is relevant, how the device is controlled, and how the setting affects use. Avoid equating ordinary recreational use with the individual’s attributed disability-related function.

Function

What does the aid enable or make sustainable?

Fit and control

Can it maneuver, wait, stop, board, or be positioned in the actual environment?

Evidence and alternatives

What individualized facts support the decision, and would a proposed alternative be effective?

Keep categories distinct

A non-standard mobility aid is a generalized review category. Other power-driven mobility device language concerns powered devices and should not be silently applied to inline skates. Historical FTA analysis should be read in its environment-specific context, not as a universal access rule.
